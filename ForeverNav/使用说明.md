# 咕咕导航 ForeverNav 2.0

《魔兽世界：无限》导航插件，用起来像手机导航软件：
**一张能缩放拖动的地图，搜一个副本或地点，路线直接画在图上，走起来顶部有距离、方向和剩余时间，走偏了自动重新规划。**

## 安装

把整个 `ForeverNav` 文件夹复制到 `World of Warcraft\_forever_\Interface\AddOns\`。

## 打开

| 方式 | 说明 |
|---|---|
| `/dh` | 打开导航窗口 |
| `/dh 死矿` | 直接导航（副本、团本、地区、码头都行，支持简称：死矿、黑龙、BRD、ZG…） |
| `/dh 收藏 名字` | 把当前位置收藏起来 |
| `/dh stop` | 停止导航 |
| `/dh scale 0.9` | 窗口太大/太小时调整（0.6～1.4）；不设置时按屏幕大小自动缩放 |

## 窗口

```
┌──────────────── 地图 ────────────────┬──────── 侧边栏 ────────┐
│ [卡利姆多][东部王国][定位我][看全程] +- │ 你在 西部荒野 · 哨兵岭   │
│                                      │ [搜索框：死矿          ] │
│        ➤ 你（箭头=朝向）              │ 全部 副本 团本 码头 鸟点 收藏│
│         ╲ 白线 跑路                   │ 结果列表（点一下选中）    │
│          ● 绿线 坐鸟 ●                │ ─────────────────────  │
│                    ╲ 蓝线 坐船        │ 死亡矿井  西部荒野·16-22 │
│                     ● 终点           │ [最省心 4分钟][最快 3分钟] │
│                                      │ ① 前往…  ② 坐鸟…  ③ …   │
│ 图例                                  │ [收藏这里]  [停止][开始导航]│
└──────────────────────────────────────┴────────────────────────┘
```

**地图**
- **滚轮缩放**（以鼠标位置为中心，最大 5 倍），**按住左键拖动**。放大后显示地区名。
- 图标：副本、团本、码头、已解锁的鸟点（绿方块）、我的收藏（星星）。**鼠标移上去看详情，点一下就导航过去**。
- **右键点地图任意位置**：导航到那个点（适合去野外某个地方）。
- 路线按颜色画出：白=跑路、绿=坐鸟、蓝=坐船、橙=飞艇、黄=地铁、紫=炉石；导航中当前这一段加粗高亮，走过的变淡。
- 跨大陆的船：在码头处标出「→ 对岸码头名」，切到另一块大陆能看到后半程。
- 「定位我」把地图移到你身边，「看全程」缩放到能看到整条路线。

**侧边栏**
- 顶部：你现在的位置、炉石、已解锁鸟点数、你的移动速度。
- 搜索 + 分类：全部 / 副本 / 团本 / 码头 / 鸟点 / 收藏。
  选「鸟点」时可以用 `<` `>` 切换角色，地图上显示那个角色解锁的鸟点。
- 目的地卡片：等级、所在地区、开放时间、入口提示。
- 「最省心 / 最快」两种方案，按钮上直接写总时间；下面是分步路线，当前步骤绿色高亮。
- 底部开关：使用鸟点、算上炉石、导航箭头、偏航重算。
- 「收藏这里」：收藏当前位置；先在搜索框输入名字再点可以起名。收藏列表里**右键删除**。

## 顶部导航条（像车载导航）

开始导航后屏幕上方出现：

- 大箭头指向下一个目标点（随你转身实时转动）
- 「前方 320码」— 离这一步的目标还有多远
- 「→ 死亡矿井 全程还剩约 6分钟」
- 当前这一步做什么，坐船时提示「中途在南海镇停靠，不要下船」

同时会设置游戏自带的导航箭头（地图标记）。**到达每一步的目标附近（35码内）自动切换下一步**，到达终点会提示并播放音效。

**偏航重算**：如果你跑到了路线以外的地区超过 10 秒，会自动从你现在的位置重新规划。

入口坐标的可靠程度：

- **有坐标**：导航到入口门口，35 码内算到达。标注「近似」的是经典怀旧服常用坐标，可能差几十码。
- **没有坐标**（大部分无限新副本，官方没公布）：地图上图标画在地区中心并变淡，导航到所在地区就算到，然后给出文字提示（比如「格罗姆高营地西边海岸，水下入口」）。

## 路线是怎么算的

- 起点是你**精确的当前位置**，终点是副本入口/收藏点的**精确坐标**。
- 地面距离用游戏的世界坐标换算成码，按**你的实际移动速度**算时间（插件会记住你跑过的最快地面速度，骑马后自动变快）。
- 地区之间按「关口」走：关口位置由两个相邻地区在地图上的交界自动推算，所以路线不会直接穿过两个地区的正中间。
- 坐鸟：按当前角色已解锁的鸟点（在任意飞行管理员处打开一次飞行地图同步，两块大陆各一次）。
- 坐船/飞艇：12 条航线，按航线长度估算航程，等船按半个班次估算。
- 炉石：能更快时会作为第一步。

## 已知限制

- **不能真的沿道路走**：暴雪不允许插件读取地形，地区内部是直线，山、河会挡路，箭头只指方向。
- 关口是根据地区范围自动推算的，不一定正好是那条山路或桥，在山多的地方（如湿地↔阿拉希的萨多尔大桥）可能偏一些。
- 无限新地区（河林、泽风岛、海加尔山）的地图和陆路连接还不确定；海加尔山的相邻关系是按传说地理推测的。
- 码头坐标：暴风城港口、南海镇、热砂港等新码头没有坐标，只有文字提示。
- 时间都是估算值，用来比较路线好坏；实际会受等船、打怪、迷路影响。

## 帮忙补坐标

站在副本入口或新码头上，输入下面这行，把聊天框打出来的内容发给作者，就能补进插件：

```
/run local m=C_Map.GetBestMapForUnit("player") local p=C_Map.GetPlayerMapPosition(m,"player") print(C_Map.GetMapInfo(m).name, GetSubZoneText(), p.x*100, p.y*100)
```
