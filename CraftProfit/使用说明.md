# 制造利润 CraftProfit

《魔兽世界：无限》（WoW Forever）插件，把拍卖行物价和专业制造联动起来：
**每个配方的材料成本是多少、成品在拍卖行能卖多少、做一次赚多少。**
同时**实时记录金币收支**：钱从哪来、花到哪去、每小时赚多少；
并用**量化指标盯着基础材料的价格**，告诉你什么时候该买、什么时候该卖。

## 安装

把整个 `CraftProfit` 文件夹复制到：

```
World of Warcraft\_forever_\Interface\AddOns\
```

最后的路径应是 `...\AddOns\CraftProfit\CraftProfit.toc`（不要多套一层文件夹）。
进游戏后在角色选择界面左下角的「插件」里确认已勾选。

> 如果插件显示“过期”：进游戏输入 `/run print(select(4, GetBuildInfo()))`，
> 把打印出的数字填进 `CraftProfit.toc` 第一行 `## Interface:` 后面。

## 第一次使用（3 步）

1. **打开专业技能窗口**（裁缝、锻造、炼金……每个专业都打开一次）
   → 插件记下你会的配方和材料。
2. **去拍卖行，点右侧的「全扫描拍卖行」**
   → 一次读取所有拍卖价格。服务器限制每 15 分钟一次；冷却期间你正常浏览、搜索拍卖行，看到的价格也会自动记录。
3. **（可选）到卖材料的商人那里打开一次商店**
   → 记下线、染料、瓶子等商人材料的价格，成本会更准。

之后打开专业窗口，右侧会出现利润面板。

## 面板说明

| 列 | 含义 |
|---|---|
| 成本 | 做一次要花的材料钱。橙色 `?` 表示有材料没价格 |
| 售价 | 做一次的成品能卖多少（已扣拍卖行手续费；如果卖商人更划算就按商人价） |
| 利润 | 售价 − 成本，绿色赚钱、红色亏钱 |
| 日销 | 估计全服每天卖出多少个成品。红色「滞销」= 基本没人买；`?` = 还没有数据 |
| 日赚 | 每次利润 × 每天能卖掉的次数。**点这一列排序，就能找到“又赚钱又卖得动”的配方** |

- 点列标题可以排序；鼠标滚轮翻页；`<` `>` 切换专业。
- **鼠标移到某一行**：显示每种材料的单价和来源（拍卖 / 商人 / 自制）、成品的最低价、在售数量和数据时间。
- **Shift+点击**：把成品链接发到聊天框。
- 在拍卖行也能点「制造利润面板」打开它，边看边买。

**材料成本怎么算**：每种材料取「拍卖价、商人价、自己做的成本」中最便宜的一个。
比如亚麻布卷：拍卖行卖 4 银，但用 2 块亚麻布自己做只要 1 银，就按 1 银算。

**市场价怎么算**：把在售的同种物品按单价从低到高排，取最便宜的 20% 数量的平均价。
这样有人挂一个离谱的超低价或超高价，也不会把价格带偏。

## 销量是怎么估算的

暴雪没有提供“成交记录”，所以插件比较**两次全扫描之间消失的挂单**来估算。一张消失的挂单要同时满足两个条件才算卖出：

1. **不是过期**：上次扫描时它的剩余时间比两次扫描的间隔还长，不可能是到期下架。
2. **不是取消重挂**：它的单价不高于这次扫描的最低价。买家总是从最便宜的买；卖家取消后重新压价挂出的单子，原价比现在的最低价高，会被排除。

所以这个数字**偏保守**，实际销量通常只会更多，不会更少。

**怎么得到数据**：隔 **15 分钟到 12 小时**，在拍卖行再点一次全扫描，每次对比都会积累一次观察。间隔超过 12 小时就没法排除过期，那次不计。日销按最近 7 天的观察计算，扫描次数越多、覆盖时间越长越准。鼠标移到某一行能看到基于几次对比、共多少小时。

**怎么用**：
- 「日销」很小或显示「滞销」：利润再高也别多做，做 1～2 个试试就好。
- 鼠标提示里的「卖完现有在售约需 X 天」：在售数量 ÷ 日销。几十天就说明市场已经饱和。
- 「日赚」是全服总量的理论上限，实际能分到多少取决于有多少人在卖。

## 鼠标提示

鼠标移到任何物品上，会多出几行：

- **拍卖价**：市场价、最低一口价、数据是多久前的
- **商人买价**：如果记录过
- **估计日销**：和当前在售数量（配方相关的物品）
- **制作成本**：如果你（或你的小号）会做，并显示按拍卖价卖出的利润

## 交易建议（量化）

盯着**基础材料**（你配方里要用、但自己做不出来、商人也不卖的东西，比如布、矿、草、皮）的价格，给出买卖建议。
打开方式：`/cpf qt`，或利润面板底部的「交易」按钮，或拍卖行右侧的「交易建议」按钮。

**每次全扫描、快速扫描都会给这些材料记价格点**：最近 24 小时保留每分钟的明细，更早的压缩成每小时一个点，保存 21 天。
统计时先按小时取平均，开着拍卖行的那几个小时不会在均价里占过大比重。
**至少要有 6 个小时有价格记录、覆盖 1 天以上才会给建议**，数据越多越准。

### 每分钟快速扫描（只扫 ★ 关注的材料）

全量扫描受服务器限制只能 15 分钟一次。对 **★关注** 的材料，插件改用逐个搜索，**拍卖行开着时每 60 秒扫一遍**：

- **加关注**：在交易建议窗口里 **右键点** 材料，或选中后点「加关注」，或 `/cpf watch [物品]`。
- **价格**：每分钟更新，走势图和指标随之更新。
- **销量更准**：搜索结果里每张挂单都有唯一编号，能精确看出同一张单子被买走了几个、哪张单子被一口价买空。
  和“两次全扫描对比”的估算相比准得多（被关注的材料优先用这个数据）。
- **即时提醒**：一旦出现「买入 / 强烈买入」，或你手里有货时出现「偏高 / 高位卖出」，聊天框会马上提示（带 ★），并播放提示音。
  同一个机会 30 分钟内不会重复提醒，除非价格又往有利方向变了 10% 以上。
- **不打扰你**：你自己在拍卖行搜索或购买后，快速扫描会暂停 20 秒；你在购买界面时不会扫描；全量扫描期间也会暂停。
- 窗口底部勾选「快速扫描★关注」开关，旁边显示状态（下次几秒 / 扫描中 / 暂停）。
- 拍卖行界面关掉就停止，这是游戏规定。

关注的材料越多一轮越慢（每个约 0.5～1 秒），建议关注 **30 种以内**。

### 看哪些指标

| 指标 | 含义 |
|---|---|
| 7日均价 | 最近 7 天所有价格点的平均 |
| 偏离 | 现价比均价高/低多少（绿色=便宜，红色=贵） |
| 波动 | 价格平时上下浮动多少（标准差） |
| 14 天分位 | 现价在 14 天里处于什么位置，0% = 最低价 |
| 24 小时趋势 | 最近 24 小时均价 vs 7 日均价，看是不是正在涨/跌 |
| 在售量 | 现在挂了多少 vs 平时挂多少；货突然变多往往要降价 |
| 日销 | 估计每天全服卖出多少，见下面“销量是怎么估算的” |

### 建议怎么得出（均值回归策略）

| 建议 | 条件 |
|---|---|
| **强烈买入 / 买入** | 现价低于均价 2 个 / 1 个波动以上；有人在买（日销 ≥ 1）；扣掉 5% 手续费后回到均价还有差价 |
| **适合备货** | 价格便宜，但卖得太慢或没差价：适合给自己做东西囤货，不适合倒卖 |
| **等待** | 价格便宜，但 24 小时内还在快速下跌、在售量暴增：别接飞刀，等跌势停 |
| **偏高可卖 / 高位卖出** | 现价高于均价 1 个 / 2 个波动以上：手里有货就卖，要用的话暂缓购买 |
| **观望** | 价格在正常区间 |

买入建议会给出**建议买入价**（均价减 1 个波动）、**建议数量**（这个价以下实际挂着多少，最多 2 天的销量，免得买了卖不掉）、
**回到均价每个预计赚多少**（已扣手续费）。卖出建议会算出你背包加银行里有几个，现在卖比平时多赚多少。

### 窗口怎么看

- 上面的列表按信号强弱排序，可以筛选「全部 / 买入 / 卖出」。
- **点一行**：下面显示 14 天每日均价柱状图（黄线是 7 日均价，最右一根是今天）、各项指标和建议理由。
- 「加关注」：把任何物品加进来一起盯（也可以用 `/cpf watch [物品]`），带 ★ 标记。
- 勾选「扫描后在聊天框提醒」：每次全扫描后，聊天框会列出最值得关注的 3 个机会。

> 这是根据历史价格做的统计判断，不是保证。服务器更新、新副本开放、节日活动都会让价格走出历史区间。
> 建议分批买，别一次压上全部金币。

## 实时收支

登录后屏幕上方会出现收支窗口，你每次金币变化都会立刻记一笔并自动分类：

| 分类 | 怎么判断 |
|---|---|
| 拍卖卖出 | 从邮箱收拍卖成交的钱（会记下卖的是什么） |
| 拍卖购买 / 拍卖押金 | 在拍卖行买东西 / 上架、取消拍卖 |
| 卖给商人 / 商人购买 / 修理 | 商人窗口打开时的金币变化；点“全部修理”单独算修理 |
| 拾取 / 任务 / 邮件 / 交易 / 飞行 / 训练师 | 对应窗口打开时的金币变化 |
| 其他 | 判断不出来的 |

- 上方按钮切换统计范围：**本次**（本次登录）/ **今日** / **7天** / **30天**。
- 显示每类的收入和支出、合计、**净收益**、**每小时赚多少**（本次登录）、**全账号今日**（所有角色加起来）。
- **拍卖行合计** = 拍卖卖出 − 拍卖购买 − 押金，就是你倒卖和卖制造品的实际盈亏。
- 下方「最近明细」列出最近 8 笔，带时间和说明。
- 右上角 `-` 收成一行迷你条，只显示本次收支和每小时收益；`+` 展开。窗口可拖动。
- 利润面板底部的「收支」按钮也能打开它。

每日汇总保留 60 天，明细保留最近 100 笔，每个角色分开记录。

## 命令

| 命令 | 作用 |
|---|---|
| `/cpf` | 打开/关闭利润面板 |
| `/cpf scan` | 全扫描拍卖行（需要先打开拍卖行） |
| `/cpf cut 5` | 设置拍卖行手续费百分比（默认 5） |
| `/cpf share 20` | 市场价取最便宜的百分之多少（默认 20） |
| `/cpf auto` | 开关：打开专业窗口时自动显示面板 |
| `/cpf price [物品]` | 查询某个物品的价格（可以 Shift+点击物品放进命令） |
| `/cpf clear` | 清空所有拍卖价格 |
| `/cpf zz` | 打开/关闭实时收支窗口 |
| `/cpf zz mini` | 收支窗口切换迷你条/详细 |
| `/cpf zz reset` | 重新开始统计“本次”收支 |
| `/cpf qt` | 打开/关闭交易建议（量化）窗口 |
| `/cpf qt alert` | 开关：扫描后在聊天框提醒交易机会 |
| `/cpf watch [物品]` | 关注/取消关注一个物品 |
| `/cpf quick` | 开关：拍卖行开着时快速扫描关注的材料 |
| `/cpf quick 60` | 设置快速扫描间隔秒数（最少 30） |
| `/cpf quick sound` | 开关快速扫描的提示音 |
| `/cpf help` | 显示命令列表 |

## 说明与限制

- 数据保存在 `WTF\Account\你的账号\SavedVariables\CraftProfit.lua`，同账号的所有角色共享价格和配方。
- 物价按物品 ID 记录，不区分随机属性（如“猛熊之”），对材料和消耗品最准。
- 只计算必需材料，不算可选材料；附魔这类不产出物品的配方只显示成本。
- 拍卖行押金没有计入成本。
- 和 Auctionator 等插件可以同时使用：它们做全扫描时，本插件会顺便记录价格。
- 插件只读取数据，**不会**自动购买、出售或制造任何东西。
